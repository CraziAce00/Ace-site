# Ace Hub

A Roblox-inspired single-page web app featuring a social-style client shell with:

- avatar customization studio
- game join cards and lobby vibe
- friends add/remove flow
- profile summary and activity
- studio panel, inventory, chat, and quick actions
- responsive layout for Codespaces and local browser use

## Run locally

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` — app layout and content
- `styles.css` — full visual design and responsive styling
- `script.js` — interactivity for friends, avatar editing, and toast feedback

## Notes

This project is a fan-made Roblox-inspired interface mockup for development and demo purposes. It is intentionally static and designed for quick local testing in GitHub Codespaces.
